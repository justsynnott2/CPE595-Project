# CPE595 Project
AI-powered student planner that tracks assignments, predicts study time with machine learning, and auto-generates study schedules.

## 1. Repository Structure

```
CPE595-Project/
├── README.md
├── .gitignore
├── frontend/
├── backend/
├── ml/
│   ├── data/
│   └── notebooks/
├── scheduling/
└── docs/
    ├── presentations/
    └── report/
```

1.1 `frontend/` holds the user facing application.
1.2 `backend/` holds the server side APIs and data persistence.
1.3 `ml/` holds the machine learning work for study time prediction, split into `data/` and `notebooks/`.
1.4 `scheduling/` holds the logic for auto generating study schedules.
1.5 `docs/` holds project documentation, split into `presentations/` and `report/`.
